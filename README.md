# Desafio Super Trunfo - Países (Nível Novato)

Olá! Eu sou o desenvolvedor responsável por este desafio de **Super Trunfo - Países**. Aqui mostro a minha implementação do **nível Novato**, que é a etapa inicial do projeto.

Este repositório contém um programa em C onde faço o **cadastro de cartas** usando apenas `scanf` para ler os valores e `printf` para exibir os resultados. O objetivo é familiarizar-me com entrada/saída básica e estruturas simples.

---

## 🧩 O que eu construí

- Um sistema para cadastrar cartas de cidades de um país fictício.
- Cada carta representa uma cidade e possui quatro propriedades:
  - **População**
  - **Área**
  - **PIB**
  - **Número de pontos turísticos**
- As cartas são codificadas com uma letra (A–H) para o estado e um número (1–4) para a cidade (por exemplo, `A01`, `B03`).

> Este nível não realiza cálculos ou comparações; é apenas cadastro e exibição.

## 🛠️ Como usar

```bash
gcc SuperTrunfoC.c -o SuperTrunfoC
./supertrunfo
```
